# ARCH-06 架构约定的持续执行：完成记录

状态：**代码与文档已完成，待维护者本地测试和 CI 通过后验收**。实施日期：2026-11-13。

## 问题是什么

ARCH-02 到 ARCH-05 加了不少规矩，也写了检查它们的测试。核对 CI 配置后发现：

| 事实                                                                                                  | 影响                                                                  |
| ----------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| CI 的测试分组是 `core`、`utils`、`animation`、`components`，**没有 `tests/shared`**                   | 前面各项的检查只在维护者本地有效。别人提交违反规矩的代码，CI 照样通过 |
| 例外散落在注释、测试里的名单和各份完成记录里                                                          | 新人不知道哪些是故意的                                                |
| 没有面向贡献者的说明，规矩只在架构文档里                                                              | 新人看不到                                                            |
| 为兼容保留的旧入口（`calendar/_date.py`、`date_input/_value.py`、`themes.FONT_FAMILY`）没有人负责移除 | 临时做法有变成默认写法的风险                                          |

## 做了什么

| 项                     | 内容                                                                                                                                                                                                               |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |

## 一个发现

删旧入口前先全仓库搜了引用，发现 **CI 的“导入检查”任务也在导入 `FONT_FAMILY`**。如果只删代码，推上去 CI 会直接变红。已改成导入 `DEFAULT_FONT_FAMILY`。

## 有意保留的差异

| 保留项                                                                     | 原因                                                                                |
| -------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| `utils/icon_utils.py` 读取已存在的主题管家                                 | 不是过渡，是长期兼容：旧图标函数默认跟随主题，要彻底断开，每个调用方都得显式传色    |
| 输入类槽位、Badge、Slider“摘下归还”                                        | 见 ARCH-05 完成记录                                                                 |
| 规矩 5（传入控件的所有权要写文档）、规矩 6（新增全局设施要有撤销）仍靠评审 | 它们是“文档里写没写”“有没有加进 `teardown()`”，不容易自动检查。不引入第三方检查工具 |
| 没有 PR 模板                                                               | 贡献指南已包含自查项。PR 模板留待有需要时再加                                       |
